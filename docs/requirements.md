# 需求分析文档 — VidFlow 万能视频下载器

## 1. 项目背景

用户需要一个能够从各平台下载视频的工具网站。现有方案（平台自带下载、第三方工具）存在以下痛点：

- 部分平台不支持下载功能
- 下载不够方便（不支持批量、有限制、清晰度受限）
- 无法跨平台统一使用
- 手机上操作不便

## 2. 目标用户

- C 端普通用户，有保存视频到本地的需求
- 以学习用途为主（尊重版权）

## 3. 核心需求

| 优先级 | 需求 | 说明 |
|--------|------|------|
| P0 | 多平台视频解析 | 粘贴链接即可识别视频信息（标题、封面、格式） |
| P0 | 视频下载 | 支持选择清晰度，下载到本地 |
| P0 | 跨平台覆盖 | YouTube、B站、抖音、Twitter 等 1000+ 网站 |
| P1 | 实时进度 | 下载进度百分比、速度显示 |
| P1 | 移动端适配 | 手机上也能正常使用 |
| P2 | 中英文切换 | 界面支持中文/English |

## 4. 扩展需求（后续）

- ✅ 视频 AI 总结（v1.2 — 字幕提取 + AI 大纲/要点/思维导图 + AI 问答）
- 字幕提取与翻译（字幕提取已实现，翻译待做）
- 会员付费系统
- 批量下载队列

## 5. 非功能性需求

- **轻量**: 无需数据库
- **前端质感**: 独特设计，吸引付费
- **简单实现**: 尽量复用开源项目，减少代码量
- **注意版权**: 仅供学习使用

## 6. 技术约束

- 技术栈以 Python 为主
- 核心下载能力依托 yt-dlp 开源项目
- 前端使用 Vue 3 + Vite
- 后端使用 FastAPI
- 禁止使用蓝紫渐变（AI 味太浓），参考 awwards 设计风格

## 7. 关键风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 平台封号 | 用户账号风险 | 免责声明，仅供学习 |
| FFmpeg 缺失 | 音视频无法合并 | 自动检测，降级下载视频流 |
| 平台需要 cookies | 部分平台无法下载音频 | 支持 cookies.txt 配置 |
| 封面跨域 | 封面不显示 | 服务端代理请求 |
